# PC games with native DualSense support

PC games that use the DualSense's **HD haptics** and/or **adaptive triggers** natively: exactly the features DS
HapticLink carries over Bluetooth. Without it, most of these games only enable them with a USB cable.

**Source:** [PCGamingWiki](https://www.pcgamingwiki.com/wiki/List_of_games_that_support_Dualsense_haptic_feedback)
(haptic feedback and adaptive trigger lists), October 2026. It's community-maintained, so it may have mistakes or
miss new games. Corrections and test reports are welcome in [Issues](../../../issues).

**Total:** 193 games with native support (23 from Sony/PlayStation, 170 from
other studios), plus 27 that only have it through community mods.

**Legend:** **Yes** native · **Partial** limited native support · **Mod** only with a community mod · **—** no ·
**✅** tested with DS HapticLink over Bluetooth.

**Tips:** turn off Steam Input for the game, and open DS HapticLink before the game. The controller's speaker and
headphone jack work in games that send audio to the DualSense (most Sony titles); this list doesn't track that.
